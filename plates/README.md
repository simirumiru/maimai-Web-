# plates フォルダ — プレート画像の置き場所

ここに画像を置くと、プレート難易度表で**プレート名を選んだ時点で自動的にその画像が入り**、
サイトを見ている全員に同じ画像が表示されます（各自でアップロードする必要がなくなります）。

## 使い方

1. 画像ファイル名を「**プレート名.png**」にする（下のリスト参照）
2. このフォルダに入れる
3. `index.html` と一緒に Vercel にデプロイする

配置後のフォルダ構成:

```
（デプロイするフォルダ）
├── index.html
└── plates/
    ├── 超極.png
    ├── 檄将.png
    └── ...
```

## 注意

- ファイル名はプレート名と**完全一致**させてください（全角・半角、漢字の違いに注意）
- 拡張子は `.png` 固定です
- 画像が無いプレートは、これまで通り「名前表示」になり、各自が個別にアップロードできます
  （つまり、**全部揃えなくても、用意した分だけ反映されます**）
- 横長のバッジ画像を想定しています（表示枠は約 112 x 40 px、`object-fit: contain` で全体が収まります）
